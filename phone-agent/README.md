# مساعد الهاتف الذكي — Android 10+

تطبيق Android Native للتحكم الصوتي بالعربية مع طبقة Accessibility.

## الوظائف الحالية

- يعمل ابتداءً من Android 10 (API 29).
- أوامر صوتية عربية مثل: «من المتصل»، «أجب»، «رجوع»، «الرئيسية».
- اكتشاف شاشة مكالمة واردة من WhatsApp عبر Accessibility.
- محاولة استخراج اسم المتصل من عناصر واجهة WhatsApp.
- نطق اسم المتصل عبر TTS.
- زر للرد على مكالمة WhatsApp عبر Accessibility.
- وضع استماع دائم اختياري عبر Foreground Service.
- GitHub Actions لبناء APK Debug تلقائياً.

## إعداد الهاتف

1. ثبّت APK.
2. امنح إذن الميكروفون.
3. افتح إعدادات إمكانية الوصول Accessibility وفعّل «مساعد الهاتف».
4. فعّل «الاستماع الدائم» إذا أردت قول الأوامر بدون فتح التطبيق.
5. جرّب مكالمة WhatsApp من جهاز آخر.

## مثال الاستخدام

عند وصول اتصال WhatsApp:

1. Accessibility تراقب واجهة WhatsApp.
2. عند اكتشاف شاشة اتصال وارد، يحاول التطبيق قراءة اسم المتصل.
3. ينطق: «مكالمة واردة من ...».
4. يمكنك قول «من المتصل؟» ليعيد الاسم.
5. يمكنك قول «أجب» أو الضغط على زر الرد.

## قيد مهم بخصوص «معرفة ماذا يريد»

هذا الإصدار يستطيع التحكم في واجهة المكالمة، لكنه **لا يدّعي أنه يستطيع قراءة صوت الطرف الآخر داخل مكالمة WhatsApp**. واجهات Android العامة لا توفر طريقة موثوقة للتطبيقات العادية لاعتراض صوت مكالمة WhatsApp أو استخراج كلام الطرف الآخر.

لذلك المرحلة التالية ستكون تصميم «مساعد المكالمات» بشكل قانوني وشفاف: بعد موافقة المستخدم، يمكن تشغيل وضع محادثة يعتمد على قدرات الصوت المتاحة للجهاز، لكن يجب اختبار توافقه مع إصدار Android والجهاز ونسخة WhatsApp قبل اعتباره مضموناً.

## الأمان والخصوصية

- لا توجد مفاتيح API داخل APK.
- الاستماع الدائم اختياري ويظهر كخدمة foreground.
- صلاحية Accessibility قوية جداً؛ فعّلها فقط لهذا التطبيق الذي تثق به.
- لا يتم تنفيذ أوامر نصية خام كأوامر نظام؛ التحكم يتم من خلال وظائف محددة.
